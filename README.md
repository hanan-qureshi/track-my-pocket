# Track My Pocket

A responsive expense tracking web app built with React. Add, edit, filter, and manage daily expenses, with all data saved locally in the browser.

This is a React rebuild of an earlier native Android version of the same app, built to deepen my frontend development skills.

## Features

- Add expenses with description, amount, category, and date
- Edit or delete existing expenses
- Filter expenses by category
- Running total, calculated automatically
- Data persists across page refreshes using `localStorage`
- Responsive layout — works on both desktop and mobile screens

## Tech Stack

- React (functional components, hooks)
- JavaScript (ES6+)
- CSS (custom, responsive with media queries)
- Browser `localStorage` for data persistence

## Running Locally

```bash
git clone https://github.com/hanan-qureshi/track-my-pocket.git
cd track-my-pocket
npm install
npm start
```

The app will run at `http://localhost:3000`.
